Calculations, integration & limitations

One calculation source

This website calls C++ functions compiled to WebAssembly. Core functions come directly from DrainGuard.cpp. The Python dashboard also calls C++ through a bridge.

Qin = C × i × A(ha) / 360
Qeff = Qcap × (1 − blockage)
R = Qin / Qeff

Categories match C++

Low: R ≤ 0.5 · Medium: 0.5 < R ≤ 0.8 · High: 0.8 < R < 1 · Critical: R ≥ 1.

Qin = 0 and Qeff = 0: Not assessed. Qin > 0 with Qeff = 0: Critical. Classification uses full precision; displayed values are rounded.

Scenario-based prototype

Default parameters come from the team files. Pipe capacity uses the full-flow Manning model and has not been verified by field measurements. No live sensors, GIS, or weather forecasts are connected. Categories are simulation indicators, not official flood warnings.
